        Set up the iPhone shortcut
        1. In PocketPal, create or edit a Pal and choose a downloaded model as its default.
        2. In Apple Shortcuts, make a shortcut named FCC PocketPal.
        3. Add Get Clipboard. Then add Ask Pal, choose that Pal, and set Message to the Clipboard variable.
        4. Add Copy to Clipboard and set its input to the Ask Pal result.
        5. In the toolbox choose PocketPal, start a task, then tap Copy prompt and Run shortcut. Return here, paste the result, and tap Run FCC step. Repeat with the next prompt.

        If you already made FCC PocketPal from FCC Chat, use the same shortcut.

        How the GitHub integration would work
        1. Fork PocketPal AI on GitHub.
        2. In the fork, implement an FCC TalentEngine with the read-only tool contract. Register it in the Talents registry.
        3. Connect the engine to an FCC workspace in the signed app. The app needs to pass the user's approved project to FCC, validate requests there, and show returned results in the activity log.
        4. Build and sign the fork with Xcode. Open it on your iPhone and test a read-only request while PocketPal is in the foreground.

        Talents are part of PocketPal’s source build. The phone workflow above uses Apple Shortcuts. iOS can suspend a background app, so this page uses explicit handoffs.
